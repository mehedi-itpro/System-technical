# 09 - Review routine and change log

## Review routine

| When | What |
|---|---|
| Every change | Update the matching document in the same sitting |
| Monthly | Check registers (assets, IPs, licences) against reality |
| Quarterly | Review every document, update the "last reviewed" date, test one backup restore |
| Yearly | Walk through a disaster recovery drill from these documents only |

If the documents were not enough to do the drill, that is the finding.
